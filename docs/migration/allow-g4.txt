# G4 allowlist: functions whose normalized disassembly may differ from
# step 0's, per G4 label (spaces as '-') and binary pair. Each row:
#
#   <label> <pair> <function>  -- <reason>
#
# The gate stays exact everywhere else: any other function that differs
# fails, a row whose function is identical fails (rows cannot linger), and
# the allowed diff is printed in full on every run for review.
#
# Step 3.3 (D13): the family version 0.4.0 replaces async's 0.1.0 and
# bridge's 0.3.0. Each C ABI version function returns a constant folded
# from TAP_SR_VERSION_*, so its one immediate changes (100 -> 400 decimal;
# 0x000300 -> 0x000400 bit-packed) and nothing else does. The rows follow
# the functions' 3.5 renames.
# 3.5 renames the functions (keys are step-0 names after the rename map) and
# moves async's probe to the family's bit-packed encoding (D13).
host-C-ABI async tap_sr_async_version   -- D13: returns TAP_SR_VERSION_* folded; 0.1.0 decimal (100) -> 0.4.0 bit-packed (0x400)
host-C-ABI bridge tap_sr_bridge_version -- D13: returns TAP_SR_VERSION_* folded; 0.3.0 -> 0.4.0 (0x300 -> 0x400)
